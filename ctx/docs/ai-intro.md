## Project Type

This is an npm package that adds the browser-side PWA channel to Alarisa. It is not the Alarisa runtime or product authority.

## Product Orientation

Alarisa serves one Principal. PWA chat is its first and primary Principal-facing interaction. This package owns the delivered browser application and its static browser-facing resources; the base `alarisa` repository owns server runtime, orchestration, memory, and capability execution.
